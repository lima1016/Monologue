# 1분 말하기 — 설계

2026-09-19. Phase 2 E의 두 번째(쉐도잉 다음). 원 설계 `2026-08-29-monologue-phase2-design.md` "1분 말하기":
한 주제로 60초 동안 끊지 않고 말하고, 교정은 중간에 끼어들지 않고 끝난 뒤 한꺼번에.
사용자 결정(2026-09-19): 교정 본 뒤 **같은 주제로 한 번 더** 말하고 비교한다. 주제는 **테마 → 레벨에 맞는 질문 3개 중 택1**(직접 입력 가능).
사용자: "설계 작성하고 바로 시작" — 스펙 검토 게이트 생략 승인.

## 흐름

1. **고르기** — 홈 모드 카드에 `1분 말하기`(5번째). `#pick`에서 테마를 고르면 서버가 그 테마·언어·레벨로 질문 3개를 만든다
   (`질문을 만들고 있어요` 표시, 수 초). 질문마다 한국어 뜻과 시작 힌트(`The best trip I've taken was...`).
   `직접 입력`도 된다(힌트 없음). 질문을 고르고 `시작`.
2. **준비 10초** — 질문·뜻·힌트가 보이는 채로 카운트다운. `바로 시작`으로 건너뛴다.
3. **60초 말하기** — **한 번의 연속 녹음**(문장마다 누르지 않는다: 유창성 연습은 멈추지 않는 것이 핵심).
   큰 타이머(0:42), 브라우저 인식으로 들리는 말이 실시간으로 흐른다(듣고 있다는 증거일 뿐, 저장·채점에 안 쓴다).
   60초에 자동으로 멈추거나 `다 말했어요`로 일찍 끝낸다.
4. **채점** — 녹음을 서버로 올려 Whisper가 한 번에 받아쓰고(구두점 포함) 문장으로 나눈다.
   문장마다 기존 교정(`_feedback`)을 차례로 돌린다 — `교정하는 중이에요 · 3/9문장` 진행 표시.
   이어서 한 번의 호출로 `원어민이라면`(같은 내용을 자연스러운 1분 답으로) + 레벨 판정.
5. **결과** — 말한 단어 수, 분당 단어, 긴 멈춤(3초 이상 무음), 고친 곳. 문장마다 `내 말 → 고친 문장` + 설명
   (내 말은 취소선 없음). 맨 아래 `원어민이라면`(▶ 듣기).
6. **한 번 더** — `같은 주제로 다시 1분` → 2회차 결과 아래에 1회차와 비교(단어 87 → 112, 고친 곳 4 → 1, 긴 멈춤 5 → 2).
   횟수 제한 없음, 비교는 항상 1회차와. `끝내기`로 세션 종료 → 리포트.

### 원 설계에서 바꾼 것
원 설계는 "한 번의 호출로 여러 문장을 처리하는 프롬프트"였다. 대신 **문장마다 기존 `_feedback`**을 쓴다.
출력 토큰 수는 어차피 문장 수에 비례해 한 번 호출로 크게 빨라지지 않고(3.1초/문장 × 약 10문장), 기존 교정은
few-shot·구두점 무시·말버릇 제거·자기인용 제거까지 실측으로 다듬어졌다. 새 일괄 프롬프트는 그 품질을 처음부터 다시
검증해야 한다. 문장 단위 호출은 진행률(3/9)도 정직하게 보여준다.

## 기록

**1회차만 기록에 들어간다.** 2회차는 같은 내용을 다시 말하는 것이라 넣으면 같은 실수가 두 번 세지고 정확도가 부풀려진다.

| | 1회차 | 2회차~ |
|---|---|---|
| 정확도·자주 걸리는 것·코치 | 들어감 | 안 들어감 |
| 복습 목록 | 고친 문장이 내일로 | 안 들어감 |
| 레벨 | 판정(세션 1개로) | 안 들어감 |
| 기록 탭 | 세션 하나 `1분 말하기 · 2회`, 리포트에 모든 회차 비교 | |
| 홈 최근 테마 | 안 나옴(시나리오가 아니라 질문) | |

## 데이터 (스키마 v9)

- `sessions.mode = 'timed'`, `topic` = 고른 질문. `scenario_id` NULL.
- 1회차 문장 = `messages` user 행 하나씩(자유 모드와 같은 모양: ok/fixed/tag/correction/suggestion). 기존 정확도·약점·복습·코치 쿼리가 그대로 동작.
- 새 테이블 `timed_rounds(session_id, round, seconds, words, long_pauses, sentences_json, native, created_at, UNIQUE(session_id, round))`.
  모든 회차의 통계와 채점된 문장(2회차~는 여기에만), `원어민이라면`.
- 녹음: 회차마다 기존 녹음 보관 경로(`/sessions/{id}/audio` 계열)로 저장하고, 세션이 끝나면 지운다(기존 약속 그대로).

## 서버

- `GET /api/timed/questions?language&theme_id` → `{questions:[{text, meaning, starter}]}` 3개. 레벨(`stable_level`, 없으면 beginner)에 맞춘다.
  모델 호출 1회, 검사: 목표 언어 문장·한국어 뜻(`_is_korean_meaning`)·힌트는 목표 언어. 2개 미만이면 1회 다시, 0개면 503. 테마·언어·레벨·날짜별 캐시.
- `POST /api/sessions` `mode:'timed'` + `topic`(질문) — 봇 첫마디 없음.
- `POST /api/sessions/{id}/timed/rounds` (multipart: 녹음) → 받아쓰기 + 문장 분리 + 통계. 응답 `{round, seconds, words, wpm, long_pauses, sentences:[{text}]}`.
  받아쓰기 실패 503(녹음은 서버에 남아 `…/rounds/{n}/transcribe`로 다시 시도).
- `POST /api/sessions/{id}/timed/rounds/{n}/grade/{i}` → 문장 i 교정(기존 `_feedback`, 문맥 = 주제). 1회차면 messages 행 저장(+복습 큐는 세션 끝에서 자유 모드와 같은 규칙).
  클라이언트가 i를 차례로 불러 진행률을 그린다. 한 문장 실패는 그 문장만 `교정하지 못했어요`.
- `POST /api/sessions/{id}/timed/rounds/{n}/native` → `원어민이라면` + (1회차면) 레벨. 실패해도 나머지는 보인다.
- `POST /api/sessions/{id}/end` — timed면 `{kind:'timed', rounds:[...], level}` 리포트, 1회차 레벨로 `end_session`, 녹음 정리.
- 문장 분리: Whisper 구간 + 문장 부호(. ? ! 。？！)로 나누고, 너무 짧은 조각(한두 단어)은 앞 문장에 붙인다.
- 긴 멈춤: Whisper 구간(VAD 후 원래 시간축) 사이 간격 ≥ 3초의 개수. 단어 수: 영어는 공백 단어, 일본어는 글자 수(구두점 제외)를 `자`로 표시.

## 화면

- 홈: 모드 카드 5개(폰은 2열 — 5번째는 한 줄 전체).
- `#pick`(1분 말하기): 테마 → 질문 3개 카드(고르면 강조) + 직접 입력 → `시작`.
- 세션 화면 대신 전용 화면 `#timed`: 준비 → 녹음(타이머·실시간 줄·`다 말했어요`) → 채점 진행 → 결과(회차 비교, 문장 목록, 원어민이라면, `같은 주제로 다시 1분` / `끝내기`).
  단계가 바뀌어도 카드 크기는 고정(자리 예약, 짧은 페이드, transform 금지). 일본어는 기존 읽기 보조(후리가나 등)를 `원어민이라면`과 고친 문장에 쓴다.
- 리포트(기록 탭에서 열기): 회차 표 + 1회차 문장 목록 + 원어민이라면.
- 마이크 권한 거부·인식 미지원: 녹음 자체가 안 되면 안내 문구, 모드 시작을 막는다.

## 실패와 이탈

- 녹음은 잃지 않는다: 받아쓰기 실패 → `받아쓰기 다시 시도`(서버에 남은 녹음), 교정 실패 → 문장은 먼저 보이고 `교정 다시 시도`.
- 녹음 중 떠나면(홈·마이페이지) 그 회차만 버린다. 끝난 회차는 남고, 세션은 기존 이어하기 규칙을 따른다.

## 품질 확인

- 실제 모델: 질문 생성(en/ja 테마 3개씩 — 레벨에 맞는가, 뜻이 한국어인가, 힌트가 자연스러운가).
- 실제 Whisper: 60초 영어·일본어 녹음(TTS로 만든 긴 말 + 사이 무음)으로 문장 분리·긴 멈춤 수가 맞는가.
- 교정은 기존 `_feedback` 그대로라 새 품질 검증 대상이 아니다. `원어민이라면`은 실제 모델로 몇 개 보고 한국어 누출·길이를 확인.
- 테스트: 회차 저장·1회차만 messages·2회차 비교·문장 분리·긴 멈춤 계산·실패 경로(503 뒤 재시도)·마이그레이션 v8→v9·화면 단계 전환과 높이. 새 테스트마다 일부러 부숴 빨개지는지.
- 브라우저 확인은 실제 크롬에서(dom-shim이 못 잡는 것 — HTMLCollection 등 — 이 있었다).

## 범위 밖

- 발음 점수, 억양 분석. 주제 즐겨찾기. 회차별 녹음 다시 듣기(세션 끝에 녹음을 지우는 약속 때문에 리포트에서는 없음; 세션 중 결과 화면에서는 `▶ 내 녹음`).
