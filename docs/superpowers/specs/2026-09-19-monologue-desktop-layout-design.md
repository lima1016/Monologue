# 데스크톱 화면 구조 — 설계

2026-09-19. 사용자: "왜 이렇게 모바일처럼 다 해놓은 거야? 전반적으로 이 프로젝트 UI 다?" 마이페이지·고르기·1분 말하기·레벨 테스트가
640px 한 줄이라 1570px 모니터에서 40%만 쓴다. 시안(`static/mock/`)을 브라우저로 보고 사용자가 골랐다.

## 공통 규칙

- 콘텐츠 너비 1200px(`--content-w` 토큰), 여백 토큰. **900px 아래에서만** 한 줄로 접힘(폰은 지금처럼 동작).
- 기능·id·이벤트 연결·접근성·잠금(inert)·스켈레톤·페이드 규칙은 그대로. 바뀌는 건 배치와 새로 보여줄 요약 정보뿐.
- 새로 보여주는 정보는 **이미 있는 데이터**만: 레벨 테스트 결과, 이번 주 목표, 연속, 정확도, 분당 단어(`/api/stats/growth`), 복습·약점 예시.
  없는 값은 지어내지 않고 그 칸을 빼거나 안내 문구.
- 홈 "오늘의 목표 문장": 가장 많이 틀린 태그의 가장 최근 고친 문장(`/stats/mypage` tags[0].examples[0].fixed, ▶는 기존 음성 경로),
  없으면 이 칸 없이 히어로가 넓게.
- 화면 크기 튐 금지(자리 예약, opacity 페이드, transform 금지), 테마 토큰만, 학습자 말 취소선 없음.
- 시안 파일(`static/mock/`)은 참고용으로 남긴다(앱에서 링크하지 않음).

## 확인

- 각 단계 node/pytest + 일부러 부수기. 모든 화면을 8010 크롬에서 1570px과 900px 아래 폭으로 확인, 주요 흐름(대화 한 턴, 쉐도잉, 1분 말하기, 레벨 테스트, 마이페이지 탭)이 그대로 동작.
