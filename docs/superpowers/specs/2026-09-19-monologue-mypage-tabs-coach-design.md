# 마이페이지 탭 + 약점 코치 — 설계

2026-09-19. 사용자: "마이페이지가 한 화면에 안 들어와서 아쉽다, 탭으로 나눠서 공간을 잘 쓰고,
정확히 어떤 게 부족한지 더 피드백을 줬으면."

## 지금 문제

- 레벨·오늘의 복습·자주 걸리는 것·지난 기록 네 패널이 세로로 이어져 복습 목록만으로 한 화면을 넘는다.
- 약점이 `어순 10회` 같은 숫자뿐이다. 무엇을 어떻게 틀렸는지 없다.
- 태그가 실제 실수를 잘못 부른다. 본 DB의 `어순` 10건 대부분은 문장을 끊지 않고 이어 말한 것,
  전치사·단어 빠뜨림(`sit the window` → `sit by the window`)이다. 숫자만 보고 연습 방향을 정하면 틀린 곳을 연습한다.

## 화면

```
← 홈   마이페이지   레벨 B1 · 최근 세션 판정      [English|日本語]
[ 복습 3 ] [ 약점 ] [ 기록 ]
┌──────────────── 탭 내용 ────────────────┐
```

- **머리줄**: 레벨은 카드 대신 한 줄(`레벨 B1` 또는 `레벨 판정까지 세션 2/3 · 발화 9/15`). 언어 선택은 그대로.
- **탭 세 개**: `복습 N`(오늘 남은 개수) · `약점` · `기록`. 역할 `tablist`/`tab`/`tabpanel`, ←/→로 이동.
- 마지막으로 본 탭을 localStorage에 기억(try/catch, 실패하면 복습). 홈의 "오늘 복습할 문장" 카드로 들어오면 항상 복습 탭.
- 탭 전환은 짧은 opacity 페이드(transform 금지 — 기존 규칙). 탭 내용 영역은 min-height를 둬서 짧은 탭으로 바꿔도
  아래가 훅 줄지 않게 한다. 각 탭은 처음 열 때 한 번 불러오고, 언어를 바꾸면 전부 무효화.
- 기존 패널 내용(복습 카드·말해보기, 지난 기록·더 보기·리포트 열기)은 동작 그대로 탭 안으로 옮긴다.
  로딩 스켈레톤·.is-refreshing·loadToken 경합 가드도 유지.

## 약점 탭

위에서부터:

1. **코치 한마디** (LLM, 아래 서버 절)
   - 2~3개 항목, 각 항목: 습관(한 줄) · 이렇게 해 보세요(한 줄) · 실제 예 `내 말 → 고친 문장` 1개.
   - 첫 생성 중에는 자리를 잡은 스켈레톤 + `코치가 최근 문장을 읽는 중이에요` 문구(10~20초).
   - 머리에 `오늘 만듦` 같은 날짜 표시.
   - 최근 30일 틀린 문장이 5개 미만이면 호출하지 않고 `틀린 문장이 5개 넘게 모이면 코치가 짚어 줘요 (지금 N개)`.
   - 실패하면 그 칸만 `코치 한마디를 만들지 못했어요` + 다시 시도 버튼. 나머지 탭은 정상.
2. **정확도 줄** — 지금 그대로(`문장 정확도 N% · 최근 30일 채점된 N문장`).
3. **자주 걸리는 것** — 막대 그대로, 각 줄을 누르면 펼쳐져 최근 예시 3개:
   `내 말`(취소선 없음) / `고친 문장` / 교정 설명(두 줄로 자르고 눌러서 전체).
   예시는 저장된 기록뿐이라 즉시 뜬다.

## 서버

- `GET /stats/mypage` 의 태그마다 `examples`: 최근 3개 `{text, fixed, correction}` 추가
  (같은 조건: 해당 언어, user, ok=0, 대본·쉐도잉 세션 제외는 기존 쿼리 조건을 따른다).
- `GET /api/mypage/coach?language=` → `{status: 'ready'|'too_few', count, day, items:[{habit, tip, said, fixed}]}`.
  - 입력: 최근 30일 틀린 문장 최대 30개(`text`, `fixed`, `tag`, `correction`).
  - 캐시: 테이블 `coach_notes(language PK, day, body JSON, created_at)` — 스키마 v8. 오늘(로컬 날짜) 것이 있으면 바로 반환,
    없으면 생성 후 저장. 하루 한 번.
  - 프롬프트: 한국어로만, 태그 이름을 믿지 말고 문장을 보고 습관을 짚을 것, 항목마다 입력에 있는 문장 하나를 예로.
  - 검사: JSON 형식, 항목 2~3개, `habit`/`tip`에 한글 있음·한자 비율(기존 번역 검사 재사용, 중국어 누출이면 1회 되묻고 그래도면 503),
    `said`/`fixed`가 입력 문장과 실제로 일치하지 않는 항목은 버린다(지어낸 예 방지). 남은 항목이 0이면 503.
  - 동시에 두 번 들어오면 한 번만 생성(언어별 lock).

## 품질 확인

- 실제 모델로 본 DB 복사본(en, ja)에 돌려서: 항목이 실제 문장과 맞는가, `어순` 뭉치를 "끊지 않고 이어 말함"처럼
  진짜 습관으로 짚는가, 한국어만인가, 지어낸 예가 걸러지는가. 결과 표를 남긴다.
- 테스트: 탭 전환·기억·홈에서 진입 시 복습 탭, 예시 펼치기, 코치 too_few/ready/실패 화면, 서버 캐시(같은 날 1회 호출),
  지어낸 예 버리기, 중국어 누출 503, 마이그레이션 v7→v8. 새 테스트마다 일부러 부숴서 빨개지는지 확인.

## 범위 밖

- 태그 분류 자체를 고치는 일(교정 프롬프트 변경). 코치가 문장을 직접 읽어 우회한다. 필요하면 다음 후보.
- 코치 수동 새로고침 버튼.

## 순서

쉐도잉 브랜치 머지(스키마 v7) 뒤, main에서 새 워크트리 `mypage-tabs`.
